# 通知解析置信度规则

版本：v1.0
更新时间：2026-05-01
适用范围：通知自动记账主链路

## 当前结论

通知自动记账只使用本地规则解析。系统先从通知标题和正文中抽取金额、方向、来源、商户和语义特征，再根据置信度分流：

- `score >= 0.86`：高置信度，未命中重复时可自动入账。
- `0.62 <= score < 0.86`：中置信度，进入待确认。
- `score < 0.62`：低置信度，直接过滤。

疑似重复记录优先进入待确认，不直接自动入账。

## 评分依据

当前规则由 `core:data` 的本地解析器维护，核心信号包括：

- 来源先验：微信、支付宝、银行短信/银行 App 等可信来源会提供基础分。
- 金额信号：识别到明确金额和币种时提高可信度。
- 方向信号：支付、付款、转出、扣款偏支出；收款、到账、转入偏收入。
- 结构信号：账户尾号、交易对象、订单号、时间、动账关键词会提高可信度。
- 风险信号：营销、资讯、估值、浮盈、优惠券、待使用补贴等非交易语义会降低可信度。

## 分流策略

1. 解析失败：返回失败结果，由通知处理状态记录错误。
2. 低置信度：标记为已过滤，不进入待确认。
3. 疑似重复：进入待确认，提示用户人工确认。
4. 高置信度且自动记账开启：写入账本。
5. 其他中置信度候选：进入待确认。
