# 第三方 SDK 清单（MVP）

更新时间：2026-04-12

## 当前集成

| 名称 | 用途 | 数据处理说明 |
| --- | --- | --- |
| Jetpack Compose / AndroidX | UI、生命周期、导航 | 本地框架依赖，不直接采集业务数据 |
| Hilt | 依赖注入 | 本地运行时依赖，不直接采集业务数据 |
| Room | 本地数据库 | 存储通知事件、账本记录、待确认记录 |
| SQLCipher | 数据库加密 | 使用端侧生成的本地密钥加密数据库 |
| DataStore | 本地设置存储 | 存储开关、留存天数、来源白名单 |
| ML Kit Text Recognition Chinese | 端内 OCR 识别 | 仅在用户开启截图分析与 OCR 后，对本地截图执行文字识别，不默认上云 |

## 当前未集成

- 未接入统计埋点 SDK
- 未接入崩溃上报 SDK
- 未接入广告 SDK
- 未接入真实云模型 SDK

## 约束

- 上线前新增任意第三方 SDK，都需要补充用途、采集字段、隐私政策链接和开关策略。
- 与自动记账无关的 SDK 默认不引入。
