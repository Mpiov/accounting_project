# 中国区合规与隐私方案（工程对齐版）

版本：v1.1  
更新时间：2026-04-14  
适用范围：当前 Android 自动记账 MVP

说明：本文用于约束当前工程实现与后续产品决策，不替代正式法律意见。上线前仍需法务复核。

## 1. 当前合规策略总原则

- 最小必要：只为自动记账处理必要数据。
- 本地优先：默认优先本地处理，避免不必要上传。
- 可关闭：所有高风险能力都必须可单独关闭。
- 可解释：自动入账结果应保留来源、解析路径和模型版本。
- 可回退：用户拒绝自动化权限后，仍可继续使用手动记账。

## 2. 当前工程落实情况

### 2.1 默认关闭项

以下能力在当前代码中默认关闭：

- 云端分析
- 图片导入：截图分析
- 图片导入：OCR 识别
- 本地语义增强 / 本地 LLM 复核

默认开启项：

- 自动记账总开关
- 微信、支付宝、银行卡短信三个通知来源

### 2.2 当前权限边界

- 通知读取
  - 用于监听交易通知并生成原始事件。
- 无障碍能力
  - 当前主要为后续图片导入或自动化预留，不再参与通知自动记账主链路。
- MediaProjection 截图
  - 当前只应服务于用户主动触发的图片处理场景，不进入通知自动记账主链路。

当前设计要求：

- 任一权限关闭后，相关链路都不应继续被调用。
- 任一权限被拒绝时，应用不能整体不可用。

## 3. 当前数据分类

### 3.1 高敏感数据

- 通知正文中的金额、商户、订单号、支付渠道
- 截图图像及 OCR 文本
- 已入账的账本流水

### 3.2 中敏感数据

- 设备与应用运行信息
- 脱敏后的错误日志
- 本地模型下载状态与路径信息

### 3.3 当前工程处理原则

- 高敏感数据优先只在端内处理。
- 截图默认不采集，只有在用户开启后才进入链路。
- 云端分析默认关闭，当前也未接入真实生产云模型。

## 4. 当前数据处理路径

### 4.1 本地路径

- 通知事件写入本地数据库。
- 本地解析器优先从通知正文抽取交易信息。
- 如用户开启本地语义增强，允许继续执行启发式增强或端侧 LLM 复核。

### 4.1.1 图片导入预留路径

- 截图和 OCR 服务于“用户主动上传图片记账”能力，其中 OCR 已可用于本地图片识别链路。
- 该路径不应和通知自动记账主链路混用。
- 当前页面截图记账通过用户主动点击常驻通知入口触发，不应在后台静默持续截图。

### 4.2 云端路径

- 当前代码仅保留云端分析开关与占位接口。
- 当前 `main` 分支没有真实云端分析接入。
- 因此当前默认实现不应发生自动的个人信息出境。

## 5. 当前本地模型合规口径

- `llama.cpp` 以 Git submodule 引入源码，不属于线上云服务。
- GGUF 模型文件通过运行时下载到应用私有目录，不打进 APK。
- 模型运行在端侧，不应默认上传通知正文、OCR 文本或账本数据。
- 本地模型只是增强链路，当前不是强制依赖项。

## 6. 当前存储与留存口径

- 通知原文默认保留 30 天。
- 截图引用默认保留 7 天。
- 账本结构化记录长期保留，后续需补充删除与导出治理闭环。
- 本地模型文件保存在应用私有目录，直到用户替换、清理或卸载应用。

当前已完成：

- 通知处理状态、错误信息、截图引用已进入数据结构。
- 设置页可调整留存天数。

当前未完成：

- 自动清理过期通知与截图的后台任务。
- 一键清空、注销删除、完整权利响应闭环。

## 7. 当前第三方与供应链约束

- 当前未接入统计埋点 SDK。
- 当前未接入崩溃上报 SDK。
- 当前未接入广告 SDK。
- 当前未接入真实云模型 SDK。
- 后续新增任何第三方 SDK，都必须补充：
  - 用途
  - 采集字段
  - 是否出端
  - 用户是否可关闭
  - 隐私政策链接

## 8. 当前用户权利实现程度

### 8.1 已具备

- 用户可关闭自动记账、云端分析、图片导入 OCR / 截图开关、本地语义增强。
- 用户可编辑账本记录。
- 用户可查看和处理待确认记录。
- 用户可生成 CSV 预览并复制导出内容。

### 8.2 仍需补齐

- 完整导出能力
- 批量删除能力
- 账户注销后的数据清空能力
- 更明确的 App 内隐私说明页

## 9. 当前上线前必须补齐的合规动作

1. 完整隐私政策与权限用途文案审校。
2. App 内权限说明与实际行为逐项核对。
3. 自动清理与用户删除能力设计补齐。
4. 如果后续接入真实云模型，重新评估：
   - 是否出境
   - 是否需要单独同意
   - 是否需要个人信息保护影响评估

## 10. 对后续开发的硬约束

- 不得把截图分析改成默认开启。
- 不得把云端分析改成默认开启。
- 不得在未补充文档和说明的情况下新增第三方 SDK。
- 不得把与自动记账无关的数据处理混入主链路。
