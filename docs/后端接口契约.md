# 后端接口契约

版本：v0.1
更新时间：2026-05-02
适用范围：手机号账号、会员、支付、全局云端学习和模型下发

## 1. 设计原则

- 服务器是账号和会员状态的唯一权威来源。
- 客户端未登录、登录失效、会员状态未由服务器确认时，一律按免费用户处理。
- 免费用户只能使用 `local-rules-v1` 普通规则算法。
- 会员用户需要服务器返回 `modelConfidenceEnabled = true` 后，才允许使用机器学习解析。
- 样本上传不再绑定会员；登录用户开启“用户改善计划”后，客户端会按固定周期上传累计的通知原文样本。
- 会员拉取模型只依赖 `modelConfidenceEnabled = true`，不强制要求用户开启用户改善计划。
- 云端训练面向所有用户上传样本汇总后的全局模型，不生成单用户定制模型。
- 所有需要账号身份的接口都使用 `Authorization: Bearer <accessToken>`。

## 1.1 当前落地状态

- 后端工程位于 `backend`，技术栈为 FastAPI + SQLite + Docker Compose。
- 腾讯云当前联调入口为 `http://122.152.220.19/v1/*`，暂不绑定域名。
- `GET /health` 由 Nginx 网关返回 `ok`，用于服务器健康检查。
- 开发阶段短信验证码固定为 `123456`，后续接入短信供应商后由服务端生成和发送。
- 新注册账号默认是 `FREE`；只有服务器数据库把会员状态改成有效 `MEMBER` 后，模型拉取接口才按功能开关放行，样本上传接口只要求登录鉴权。
- 当前支付接口会创建 30 分钟有效的订单占位，不返回真实微信支付参数。
- 在接入真实支付回调前，订单收款确认只允许 SSH 隧道 Web 后台操作；后台确认后会自动把订单标记为已支付并开通会员。
- 临时会员开通仍保留服务器本地 CLI 和 SSH 隧道 Web 后台入口，用于补偿、测试或特殊情况，不提供公网管理接口。
- Web 管理后台只绑定服务器本机 `127.0.0.1:8080`，需要通过 SSH 隧道访问，不经过公网 Nginx。
- 服务端已新增全局模型注册表和训练任务表，客户端拉取的是当前激活的 `GLOBAL` 模型版本。
- `trainer` 容器默认北京时间每天凌晨 3 点检查一次训练条件，满足样本和质量门槛才发布新模型。

## 2. 通用响应

所有接口统一返回：

```json
{
  "requestId": "req_202605020001",
  "success": true,
  "data": {},
  "error": null,
  "serverTime": 1777651200000
}
```

失败时：

```json
{
  "requestId": "req_202605020002",
  "success": false,
  "data": null,
  "error": {
    "code": "AUTH_TOKEN_EXPIRED",
    "message": "登录已过期，请重新登录"
  },
  "serverTime": 1777651200000
}
```

常用错误码：

- `BAD_REQUEST`：请求字段缺失或格式错误。
- `AUTH_REQUIRED`：缺少登录态。
- `AUTH_TOKEN_EXPIRED`：访问令牌过期。
- `MEMBERSHIP_REQUIRED`：当前账号不是会员。
- `PAYMENT_PENDING`：订单仍在支付中。
- `RATE_LIMITED`：请求过于频繁。
- `SERVER_ERROR`：服务器内部错误。

## 3. 账号接口

### 3.1 发送验证码

`POST /v1/auth/sms-code`

请求：

```json
{
  "phone": "13800138000",
  "scene": "login"
}
```

响应：

```json
{
  "cooldownSeconds": 60,
  "expiresInSeconds": 300
}
```

说明：

- `scene` 当前固定为 `login`，表示登录或自动注册。
- 服务端负责短信频控、图形验证或风控策略，客户端只展示返回结果。

### 3.2 验证码登录/注册

`POST /v1/auth/login`

请求：

```json
{
  "phone": "13800138000",
  "code": "123456",
  "deviceId": "android-device-id",
  "appVersion": "1.0.0"
}
```

响应：

```json
{
  "userId": "user_10001",
  "phone": "13800138000",
  "accessToken": "access-token",
  "refreshToken": "refresh-token",
  "accessTokenExpiresAt": 1777654800000,
  "refreshTokenExpiresAt": 1780243200000,
  "isNewUser": false
}
```

客户端映射：

- `userId` -> `AuthSession.userId`
- `phone` -> `AuthSession.phone`
- `accessToken` -> `AuthSession.accessToken`
- `refreshToken` -> `AuthSession.refreshToken`
- 登录成功后立即调用 `GET /v1/membership/status`。

### 3.3 刷新令牌

`POST /v1/auth/refresh`

请求：

```json
{
  "refreshToken": "refresh-token"
}
```

响应：

```json
{
  "accessToken": "new-access-token",
  "refreshToken": "new-refresh-token",
  "accessTokenExpiresAt": 1777654800000,
  "refreshTokenExpiresAt": 1780243200000
}
```

## 4. 会员接口

### 4.1 查询会员状态

`GET /v1/membership/status`

鉴权：必需。

响应：

```json
{
  "userId": "user_10001",
  "phone": "13800138000",
  "tier": "MEMBER",
  "expiresAt": 1777654800000,
  "modelConfidenceEnabled": true,
  "cloudLearningEnabled": true,
  "serverVerified": true
}
```

客户端映射：

- `tier` -> `MembershipStatus.tier`
- `expiresAt` -> `MembershipStatus.expiresAt`
- `modelConfidenceEnabled` -> `MembershipStatus.modelConfidenceEnabled`
- `cloudLearningEnabled` -> `MembershipStatus.cloudLearningEnabled`
- `serverVerified` 必须为 `true` 才能解锁会员能力。

服务端规则：

- 未支付、会员过期或账号异常时返回 `tier = FREE`。
- 会员过期判断以 `serverTime` 为准。
- 删除 App 后，用户重新登录即可通过本接口恢复会员状态。

## 5. 支付接口

### 5.1 创建会员订单

`POST /v1/payments/membership-orders`

鉴权：必需。

请求：

```json
{
  "plan": "YEARLY",
  "payChannel": "WECHAT_APP"
}
```

响应：

```json
{
  "orderId": "order_202605020001",
  "plan": "YEARLY",
  "amountCents": 1900,
  "paymentState": "CREATED",
  "expiresAt": 1777653000000,
  "wechatAppPayParams": {
    "appId": "wx_app_id",
    "partnerId": "merchant_id",
    "prepayId": "prepay_id",
    "packageValue": "Sign=WXPay",
    "nonceStr": "nonce",
    "timestamp": "1777651200",
    "sign": "server_sign"
  }
}
```

客户端映射：

- `orderId` -> `MembershipPaymentOrder.orderId`
- `plan` -> `MembershipPaymentOrder.plan`
- `amountCents` -> `MembershipPaymentOrder.amountCents`
- `wechatAppPayParams` -> App 调起微信支付 SDK 所需参数。

服务端规则：

- 当前正式开放套餐为限时年卡，`YEARLY = 1900` 分，后台确认收款后开通 365 天会员。
- 订单默认 30 分钟过期，可通过 `AUTOBOOK_PAYMENT_ORDER_EXPIRE_MINUTES` 调整。
- 待支付订单在查询接口或后台订单列表读取时会自动从 `CREATED/PAYING` 变为 `EXPIRED`。

### 5.2 查询订单状态

`GET /v1/payments/membership-orders/{orderId}`

鉴权：必需。

响应：

```json
{
  "orderId": "order_202605020001",
  "paymentState": "PAID",
  "paidAt": 1777651300000,
  "expiresAt": 1777653000000
}
```

支付完成后客户端必须重新调用 `GET /v1/membership/status`，不直接根据订单状态本地开通会员。

## 6. 训练样本接口

### 6.1 上传训练样本

`POST /v1/cloud-learning/training-samples`

鉴权：必需。

上传规则：

- 免费用户和会员用户都可以上传样本，只要客户端已登录且本地“用户改善计划”处于开启状态。
- 客户端不再因为待确认反馈单独排加速上传任务，所有新样本、纠错样本和原文样本都进入同一个本地待上传队列，再由 WorkManager 周期批量上传。
- `RAW_NOTIFICATION_UNREVIEWED` 表示仅保存了通知原文、包名、来源和处理状态的原文样本；这类样本先进入后台样本池和人工排查视图，默认不直接参与当前线性置信度训练。

请求：

```json
{
  "clientBatchId": "batch_202605020001",
  "deviceId": "android-device-id",
  "appVersion": "1.0.0",
  "samples": [
    {
      "id": 1,
      "sampleLocalId": 1,
      "notificationId": 42,
      "createdAt": 1777651200000,
      "updatedAt": 1777651200000,
      "packageName": "com.tencent.mm",
      "rawTitle": "微信支付",
      "rawText": "向便利店支付18.80元",
      "rawPostedAt": 1777651199000,
      "sourceApp": "WECHAT",
      "modelVersion": "local-rules-v1",
      "parsePath": "local-parser/rules",
      "amount": 18.8,
      "direction": "EXPENSE",
      "merchant": "便利店",
      "channel": "微信支付",
      "candidateTimestamp": 1777651199000,
      "category": "待分类",
      "orderId": null,
      "confidenceScore": 0.91,
      "confidenceLevel": "HIGH",
      "confidenceReason": "规则=local-rules-v1；最终=0.9100",
      "features": {},
      "routeDestination": "LEDGER",
      "processStatus": "LEDGER_POSTED",
      "feedbackLabel": "AUTO_LEDGER_UNREVIEWED",
      "feedbackSource": null,
      "feedbackAt": null,
      "editedManually": false,
      "feedbackNote": null,
      "parsed": {
        "amount": 18.8,
        "direction": "EXPENSE",
        "merchant": "便利店",
        "channel": "微信支付",
        "timestamp": 1777651199000,
        "category": "待分类",
        "orderId": null
      },
      "corrected": null,
      "changedFields": []
    }
  ]
}
```

响应：

```json
{
  "accepted": 1,
  "updated": 0,
  "duplicated": 0,
  "rejected": 0,
  "nextCursor": null
}
```

约束：

- 单批建议最多 200 条。
- 服务端优先用 `userId + sampleLocalId` 做贡献者维度幂等更新；旧客户端缺少 `sampleLocalId` 时退回 `userId + notificationId + createdAt`。
- 同一个本地样本后续因用户纠错重新上传时，服务端会覆盖 `raw_json`，保证 `corrected` 和 `changedFields` 等强监督信号进入训练池。
- 所有通过校验的样本都会写入 `GLOBAL` 全局样本池，训练任务汇总所有用户数据后发布统一模型。
- 上传接口必须校验 `cloudLearningEnabled = true`。
- 样本包含通知原文，服务端需要按隐私数据处理。
- `parsed` 是模型当时给出的字段快照；`corrected` 和 `changedFields` 来自用户在待确认页或账本编辑页的后续操作。
- 当前全局置信度模型不会把 `corrected` 和 `changedFields` 当作输入特征，避免训练时偷看答案；这些字段用于后续金额选择、方向分类和商户抽取等专项模型。

## 7. 模型接口

### 7.1 拉取会员全局模型

`GET /v1/cloud-learning/global-model`

鉴权：必需。

查询参数：

- `currentVersion`：客户端当前已生效模型版本，可为空。

响应：

```json
{
  "modelVersion": "global-linear-confidence-bootstrap-20260502",
  "modelScope": "GLOBAL",
  "modelType": "LINEAR_CONFIDENCE",
  "validUntil": 1777737600000,
  "minAppVersion": "1.0.0",
  "trainedSampleCount": 0,
  "publishedAt": 1777651200000,
  "weights": {
    "bias": -2.0,
    "source.trusted_payment": 1.55,
    "source.trusted_bank": 1.4,
    "amount.with_currency": 1.2,
    "direction.expense": 1.05,
    "risk.marketing": -1.15
  },
  "thresholds": {
    "high": 0.86,
    "medium": 0.62,
    "threshold.asset_valuation_max_score": 0.45,
    "threshold.direction_conflict_max_score": 0.61,
    "threshold.unreliable_amount_max_score": 0.85,
    "threshold.weak_marketing_max_score": 0.55
  },
  "signature": "server-signature"
}
```

约束：

- 服务端必须校验 `modelConfidenceEnabled = true`。
- 拉取模型不要求用户开启“用户改善计划”，因为该开关只表示是否上传原文贡献训练。
- 当前模型为全局模型，所有会员客户端在同一版本周期内拉取同一个模型包。
- `weights` 必须使用客户端稳定特征键，例如 `source.trusted_payment`、`amount.with_currency`、`direction.expense`、`semantic.transaction_scene`、`risk.asset_valuation`。
- 客户端会保存版本、权重、阈值、发布时间和有效期；会员解析器优先使用本地保存的服务器模型。
- 客户端只允许服务器通过 `threshold.*` 收紧风险上限，不能放宽资产估值、方向冲突、金额弱证据和营销弱交易证据保护。
- 拉取失败、模型过期、权重为空或用户非会员时，客户端回退普通规则或内置会员模型，不本地伪造会员能力。

## 7.2 全局训练任务

训练任务不对客户端开放 HTTP 接口，当前只通过服务器本地 CLI、`trainer` 定时容器和 SSH 隧道管理后台触发。

默认策略：

- 每天凌晨 3 点检查一次。
- 新增有效标签样本少于 100 条时跳过。
- 总有效标签样本少于 100 条时跳过。
- 正负样本任一类别少于 10 条时跳过。
- 验证准确率低于 0.65 时跳过。
- 负样本误判率高于 0.25 时跳过。

训练结果：

- `SKIPPED`：样本不足、标签不足或质量不达标，不发布新模型。
- `PUBLISHED`：写入 `model_versions` 并把新版本置为当前激活全局模型。
- `FAILED`：训练过程异常，保留错误信息，线上模型不变。
