# 客户端增强现状与后续计划

版本：v0.4  
更新时间：2026-04-15  
适用范围：当前 Android 客户端主线现状

## 1. 这份文档的定位

原始版本是一份“计划文档”，但当前对应能力大部分已经落地。  
为了方便后续新对话直接理解现状，本文改为“已完成内容 + 下一步建议”的混合文档。

## 2. 当前客户端已完成能力

### 2.1 账本浏览能力

- 已支持“今日 / 本月 / 全部 / 日历”四种时间筛选方式。
- 已支持月历浏览与按具体日期查看流水。
- 已支持按天查看收入 / 支出概览。
- 已支持搜索与基础账本浏览。

### 2.2 手动记账能力

- 已支持新建、编辑账本记录。
- 已支持快捷模板预填。
- 当前内置模板包括：
  - 早餐
  - 午餐
  - 打车
  - 购物
  - 工资
  - 转账

### 2.3 设置页能力

- 已支持自动记账总开关。
- 已支持云端分析开关。
- 已支持图片导入截图分析开关。
- 已支持图片导入 OCR 开关。
- 已支持本地语义增强开关。
- 已支持通知来源白名单。
- 已支持通知与截图留存天数调整。
- 已支持本地账本概览。
- 已支持 CSV 预览与一键复制。
- 已支持在设置页直接启动/关闭“截图快捷记账”常驻通知入口，`captureEnabled` 不再只是展示状态。

### 2.4 本地模型能力

- 已在设置页展示可选本地模型。
- 已支持模型选择、下载和状态刷新。
- 当前推荐模型为 `Qwen3 1.7B GGUF`。
- 当前已接入 `llama.cpp + GGUF` 真本地推理运行时。
- 图片导入在关闭云端分析且开启 OCR 后，已可走 `ML Kit OCR + 本地 Qwen` 生成建议。
- 图片导入和截图分析的云端路径对外统一命名为“云端大模型”，当前实际配置模型为 `gemini-3-flash-preview`。
- 图片导入编辑页已支持展示多候选结果，并可在候选之间切换查看与确认。
- 当前页面截图记账已可通过设置页启动常驻通知入口，并在后台执行截图分析。
- 截图待确认结果当前不会强制跳转页面，而是通过总览页提醒卡和底部待确认 badge 做显性提示。

### 2.5 调试与联调能力

- Debug 构建已提供通知注入能力。
- 可用于在真机上快速验证通知入库、解析、待确认与入账链路。

## 3. 当前已完成的测试与验证

当前主线已经验证通过：

- `.\gradlew.bat :app:testDebugUnitTest`
- `.\gradlew.bat :core:data:testDebugUnitTest`
- `.\gradlew.bat :service:notification:testDebugUnitTest`

## 4. 当前客户端仍然欠缺的部分

### 4.1 体验层欠缺

- 权限失败后的引导仍可继续细化。
- 模型下载失败与恢复的用户提示仍可补强。
- 图片导入记账链路已经能够生成建议；当前页面截图记账也已具备最小可用入口，但候选选择体验和结果说明仍可继续优化。
- 截图快捷入口当前仍以“设置状态 + 前台服务状态”弱一致为主，尚未做服务存活探针级别的双向校准。

### 4.2 工具层欠缺

- 没有“立即清理过期数据”入口。
- 没有完整的正式导出流程，只是 CSV 预览与复制。
- 没有用户注销或批量删除闭环。

### 4.3 观测层欠缺

- 没有正式崩溃上报能力。
- 没有结构化线上埋点与稳定性看板。

## 5. 建议的下一轮客户端工作

### 5.1 第一优先级

- 增加通知与截图的本地清理入口。
- 补强权限拒绝、授权失效、模型不可用时的提示文案。
- 为图片导入中的 OCR / 本地 Qwen 链路增加更清晰的状态反馈与错误提示。
- 为“当前页面截图记账”补充更明确的结果通知、候选切换与失败恢复体验。

### 5.2 第二优先级

- 完成正式导出能力，而不只是 CSV 预览。
- 补充批量删除和历史管理。
- 继续优化待确认页的批处理体验。

### 5.3 第三优先级

- 增加更细粒度的调试追踪面板。
- 增加稳定性观测与错误归因信息。
