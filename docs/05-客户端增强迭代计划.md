# 客户端增强迭代计划

版本：v0.2  
日期：2026-04-13  
范围：当前 Android 客户端分支增量开发

## 当前状态

- 已完成：账本日历筛选与日级概览
- 已完成：手动记账快捷模板
- 已完成：设置页数据概览与导出增强
- 已验证：`./gradlew.bat :app:testDebugUnitTest`
- 已验证：`./gradlew.bat assembleDebug`

## 目标

在现有“自动记账主链路可运行”的基础上，继续补强客户端体验，让账本更适合日常持续使用，而不只是验证链路是否打通。

本轮迭代重点放在以下三个方向：

1. 账本浏览更直观：增加日历化入口，降低按天回看流水的成本。
2. 手动记账更高效：补充快捷模板，减少重复输入。
3. 设置页更实用：补充本地数据概览和导出结果的可读性，提升“可检查、可带走”的能力。

## 当前现状

- 已有 Onboarding、账本首页、待确认列表、设置页、手动编辑页。
- 已支持账本搜索、按今日/本月/全部筛选、手动新增与编辑、待确认处理、CSV 预览导出。
- 自动记账与本地持久化链路已经联通，适合继续做客户端层增强。

## 本轮功能规划

### 功能 1：账本日历筛选与日级概览

目标：让用户可以从“按时间范围粗筛”进化到“按具体日期查看”，快速回顾某一天的支出和收入。

计划内容：

- 在账本首页增加“日历模式”入口。
- 展示当前月份的简化日历视图。
- 用视觉标记提示哪些日期存在流水。
- 点击某一天后，仅展示该日记录，并刷新收入/支出汇总。
- 保留原有“今日 / 本月 / 全部”筛选，不破坏现有使用路径。

验收标准：

- 无数据时日历仍能正常显示。
- 选中日期后列表、汇总与空状态文案同步变化。
- 切换回其它筛选范围后不会产生状态错乱。

### 功能 2：手动记账快捷模板

目标：降低手动录入成本，让“补账”或“快速记一笔”更接近日常产品体验。

计划内容：

- 在手动记账页增加常用模板区。
- 模板一键填充方向、分类、常用备注或默认对象。
- 首批内置若干高频模板，例如早餐、午餐、打车、购物、工资、转账。
- 模板仅作为预填，不限制用户继续编辑。

验收标准：

- 模板点击后表单即时更新。
- 新建、编辑、待确认处理三种模式行为清晰，不出现误覆盖关键字段的情况。
- 原有手动输入流程保持可用。

### 功能 3：设置页数据概览与导出增强

目标：让设置页从“纯配置页”升级为“轻量工具页”，帮助用户快速检查本地账本状态。

计划内容：

- 增加账本数据概览卡片，例如总记录数、手动记录数、待确认数量、最近记账日期。
- 增强导出预览可读性，显示导出行数、最近一次记录范围或摘要信息。
- 保持纯本地实现，不依赖新后端。

验收标准：

- 设置页在空账本与有账本两种状态下都能正常展示。
- 导出预览仍保持原有 CSV 文本能力，同时有更直观摘要。
- 不引入新的权限依赖。

## 实施顺序

1. 先提交本计划文档，固定本轮边界。
2. 完成功能 1 并单独提交。
3. 完成功能 2 并单独提交。
4. 完成功能 3 并单独提交。
5. 最后做一次构建或测试验证，整理结果。

## 开发约束

- 不改动自动记账主链路的核心判断逻辑，优先做客户端体验增强。
- 每完成一个独立功能即执行 `git add` 与 `git commit`。
- 若某个点卡住较久，则停止深挖，转向下一项，保证分支持续产出。
