# Android 当前架构总览

版本：v1.5
更新时间：2026-05-02
适用范围：当前 `main` 分支代码现状说明

## 1. 文档用途

这份文档用于给后续开发对话、代码评审和问题排查提供“当前实现状态”的统一上下文。  
如果后续讨论与本文冲突，以代码为准，再回头修正文档。

## 2. 当前实现结论

- 项目是一个可运行的 Android 自动记账 MVP。
- 通知主链路为：通知监听 -> 本地规则解析 -> 自动入账 / 待确认 / 过滤。
- 监听到系统通知后，不再进入图片识别、云端通知解析或额外增强链路。
- 置信度增强已具备本地训练样本闭环和会员全局模型落地链路；免费用户只走普通规则算法，不能使用机器学习。
- 图片导入和当前页面截图仍是用户主动触发能力，当前只保留“云端大模型建议 + 本地规则后处理”与“手动确认草稿”两条路径。
  - 已新增 `backend` 后端技术骨架，并且客户端账号、会员、支付订单、样本上传、全局模型拉取和本地模型落盘已接入该后端。

## 3. 模块结构

### 3.1 应用与功能模块

- `app`
  - 应用入口、导航、页面装配、ViewModel 挂载。
  - 包含设置页、手动编辑页、截图记账入口、导出预览和 debug 注入整合逻辑。
- `feature:onboarding`
  - 首次引导、权限状态展示、自动记账与云端分析开关入口。
- `feature:ledger`
  - 账本首页、时间筛选、日历模式、列表与统计展示。
- `feature:pending`
  - 中置信度记录与疑似重复记录的待确认列表及确认处理。

### 3.2 核心能力模块

- `core:model`
  - 领域模型、账号会话、设置模型、服务器会员状态、云端学习状态、通知状态、交易候选、账本记录和图片导入建议等公共类型。
- `core:common`
  - 通用格式化、权限状态检查、设置 Intent 和安全日志格式化工具。
- `core:database`
  - Room 数据库、DAO 与本地账本持久化。
- `core:data`
  - 仓储实现、DataStore 设置、手机号账号后端接入、通知处理流水线、本地通知规则解析、训练样本闭环、会员云学习后端接入、图片候选后处理、截图协调。
- `core:network`
  - 云端大模型图片导入代理客户端。

### 3.3 系统服务模块

- `service:notification`
  - `NotificationListenerService` 实现、通知内容抽取、调试追踪与事件入库入口。
- `service:automation`
  - `AccessibilityService` 实现，提供用户主动截图所需的打开通知栏、截图和收起系统面板能力。

### 3.4 后端模块

- `backend`
  - FastAPI 后端工程，当前部署到腾讯云轻量服务器。
  - 使用 SQLite 保存手机号账号、刷新令牌、会员状态、支付订单、训练样本和全局模型版本。
  - 通过 Docker Compose 与 Nginx 网关运行，公网入口当前为 `http://122.152.220.19/v1/*`。
  - `trainer` 容器每天凌晨检查全局样本池，满足数量、标签分布和验证质量门槛后发布新全局模型。
  - 管理后台只绑定服务器本机 `127.0.0.1:8080`，通过 SSH 隧道访问，用于人工发放和撤销会员。
  - 当前短信验证码使用开发固定码，微信支付参数和真实全局模型训练任务仍是后续接入项。

## 4. 当前主链路

### 4.1 通知入账链路

1. `service:notification` 监听系统通知，并抽取标题、正文、展开文本和多行文本。
2. `core:data` 将通知事件写入本地数据库，补齐来源应用、处理状态和错误信息。
3. `ModelRouterImpl` 读取服务器确认过的会员状态：
   - 免费、未登录或未被服务器确认会员：使用 `local-rules-v1` 普通规则算法。
   - 服务器确认会员且开通模型权限：使用 `local-linear-confidence-v1` 机器学习模型。
4. `TransactionProcessingPipeline` 根据置信度、自动记账开关和账本级判重结果分流：
   - 高置信度且未重复：写入账本。
   - 中置信度或疑似重复：进入待确认。
   - 低置信度：直接过滤。
5. 分流结果会写入本地训练样本表，包含通知原文、模型特征、置信度、落点和后续用户反馈。

### 4.2 用户改善计划与会员模型骨架

1. `AuthRepository` 提供手机号验证码登录/注册骨架，验证码校验和令牌由服务器返回。
2. `MembershipRepository` 以服务器会员状态作为唯一权威，本地未登录或服务器请求失败时不会授予会员能力。
3. `SettingsRepository` 默认开启 `userImprovementPlanEnabled`，登录用户开启后即可按周期上传通知原文样本，是否会员不影响样本贡献。
4. 免费用户可以贡献样本，但不会拉取全局模型，继续使用普通规则算法。
5. 所有登录用户上传的 JSONL 训练样本进入服务器全局样本池，后续训练任务综合所有用户数据发布统一模型。
6. 如果用户在待确认或账本编辑中修正字段，训练样本会导出 `parsed`、`corrected` 和 `changedFields`，让服务器知道金额、方向、商户、时间等哪些字段被改过。
7. 会员模型拉取只依赖服务器 `modelConfidenceEnabled`，即使用户关闭用户改善计划，也可以拉取服务器当前激活的全局模型。
8. `CloudModelStore` 会把服务器模型版本、权重、阈值、发布时间和有效期保存到本地 DataStore；App 重启后会员解析器仍会优先使用这份服务器模型。
9. 服务器模型只允许覆盖线性权重和收紧风险阈值，资产估值、方向冲突、金额弱证据、营销弱交易证据等安全上限不能被云端放宽。
10. 客户端通过 WorkManager 自动同步：会员状态在启动 / 回前台时刷新，并每 12 小时兜底刷新；训练样本本地持续累计并每 1 小时周期上传一次，不再为待确认反馈单独创建加速上传任务；全局模型每 24 小时拉取一次。
11. 新增训练样本不会按天清空，而是在本地持续累计；上传成功后只标记已同步样本，后续字段纠错会重新变脏并进入下一批上传。
12. 当前真实账号、会员校验、支付订单、上传门禁、全局模型注册表、定时训练检查、模型下载和客户端模型落盘已完成客户端到服务端联调；真实短信供应商和支付回调仍未接入。

### 4.3 用户主动图片链路

1. 用户在编辑页选择图片，或通过常驻通知触发当前页面截图。
2. `ImageImportAnalyzer` 根据云端分析开关决定：
   - 开启云端分析：调用 `DirectCloudImageImportApi` 走云端大模型代理。
   - 关闭云端分析：返回手动确认草稿。
3. `ImageImportCandidatePostProcessor` 对候选执行本地规则后处理：
   - 过滤已退款 / 已退还 / 已撤销 / 已取消候选。
   - 执行批内去重。
   - 与本地账本做历史判重。
   - 按置信度、时间完整度和金额完整度择优。
4. 图片分析结果始终作为建议，保存前仍需用户确认或满足截图链路的自动入账条件。

## 5. 用户可见链路

- Onboarding：解释权限、能力和默认策略。
- Overview：展示收入、支出、结余、预算、待确认提醒和近期流水。
- Ledger：按年/月查看账本，并可进入月份详情。
- Charts：展示支出趋势和分类分布。
- Pending：确认、编辑、忽略待确认候选。
- Settings：手机号登录/注册、切换自动记账、云端分析、会员全局云端学习、截图入口、来源白名单、留存天数、预算和 CSV 预览。
- Entry Editor：手动新增、编辑账本、处理待确认、图片导入建议回填。

## 6. 当前默认策略

- `autoAccountingEnabled = true`
- `cloudAnalysisEnabled = true`
- `cloudLearningEnabled = true`
- `captureEnabled = false`
- `notificationRetentionDays = 30`
- `screenshotRetentionDays = 7`
- 默认启用来源：微信、支付宝、银行卡短信、未知来源

这些配置由 `DataStore` 持久化，设置页可直接修改。

## 7. 当前已完成的客户端能力

- 首次引导与权限状态刷新。
- 通知监听、原始通知入库、处理状态更新和安全日志摘要。
- 本地通知文本规则解析。
- 本地训练样本记录、反馈标注和 JSONL 导出。
- 用户字段纠错快照导出，可识别金额、方向、商户、时间、分类、订单号和备注是否被修改。
- 手机号账号技术骨架。
- 服务器权威会员状态门禁。
- 会员全局云端学习技术骨架，包括支付订单、样本上传、全局模型拉取、本地模型落盘和会员解析器权重接入。
- 自动入账、待确认、低置信度过滤和账本级判重。
- 账本首页、月份总览、月份详情、记录时间线和搜索。
- 手动记账、编辑、删除、快捷模板和图片导入建议回填。
- 预算设置、设置页账本概览和 CSV 预览。
- 当前页面截图记账常驻入口。
- Debug 构建下支持通知注入调试服务，便于真机联调通知解析链路。
